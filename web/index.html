          Scaling ladder

          Every row is one prompt, timed from typing to a published skill agent, with success measured on 20 held-out scenes. Tier 1 is one motion, tier 2 carries a block somewhere, tier 3 chains published skill agents.

          Skill library

          Every finished skill is saved as a tile: a frame from its own rollout, its success on held-out scenes, and how long it took to train. Replay it, test it on scenes it has never seen, remix it with a new prompt, or start a new skill from the base policy. Each tile is also its own agent with a chat endpoint.
